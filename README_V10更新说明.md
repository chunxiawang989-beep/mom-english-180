# 妈妈英语·180天 V10｜丰富句型版

## 这次为什么重做
V9 的主题虽然扩展到180天，但句子骨架仍过度模板化。
V10 改为“真实场景口语 + 多种沟通功能 + 孩子可说 + 句型总结”。

## 课程内容
- 180天 = 180个不重复主题
- 每天默认18句，可自行编辑/删除/添加到20句
- 每天前4句：高度场景化的直接口语
- 后14句：从该类场景的大型自然表达池中组合，包括选择、引导、描述、比较、条件、协商、情绪、复盘、孩子回应等
- 课程共约3240个学习位，当前英文表达约1430个不同句子/表达反复在合适场景迁移使用
- 课程识别到约580种句型/表达结构；每天实际显示约13–14种不同结构

## 参考框架
1. DK《I Can Do That!: 1,000 Ways to Become Independent》：独立生活技能、分步骤自理。
2. 《美国家庭万用亲子英文》：家庭一日、家务、称赞与劝告、游戏、美术、户外、情绪、健康、料理、周末、交通、绘本/影片、孩子成长、朋友与学校、紧急情况等情境。
3. APP句子为重新整理和原创表达，不复制两本书整页原文。

## 新增“今日句型总结”
每一天从18句里抽出6个最值得迁移的结构，显示：
- 句型结构
- 沟通功能
- 当天例句

例如：
- Would you like A, or B?
- What made...?
- If..., we can...
- before / after / when
- instead of + -ing
- I noticed + clause

## 新增“180天句型地图”
进入底部“句型”模块，可以按类别/关键词查看课程句型结构及跨场景例句。

## DK场景辅助库
保留62个独立生活技能场景。
DK官方公开介绍明确举例的技能会标记“DK公开示例”；其余为同类独立技能扩展。
由于公开官方资料没有提供完整原书目录，本APP不声称逐页复制原书全部内容。
如果以后上传您手头DK书的目录或页面，可继续按原书场景逐项对齐。
