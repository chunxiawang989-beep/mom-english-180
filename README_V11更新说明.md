# 妈妈英语·180天 V11｜自然美音版

## 为什么V10声音机械
V10的本地音频由离线eSpeak批量生成。
它稳定、无需联网，但音色本身就是传统合成音，不可能通过简单调语速变成自然人声。

## V11朗读逻辑
默认：自然英文（推荐）

播放顺序：
1. 国内网络可访问的自然英文在线发音
2. en-US 在线美音
3. APP原有本地离线音频（仅兜底）

可以手动选择：
- 自然英文（推荐）
- 国内网络英文
- en-US 美音
- 本地离线（备用）

## 优点
- 正常联网时不再默认播放机械的eSpeak音频
- 自己新增的句子也能直接在线朗读
- 在线服务失败时，原来的离线音频仍然保留，不影响使用
- 不需要重新上传13个audio音频包
