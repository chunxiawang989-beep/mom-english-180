# 妈妈英语·180天 V12｜统一标准美音版

## 发音标准
用户指定：
Day 1 的 “Open your eyes.” 为全APP发音标准。

V12不再自动混用多个TTS音源。

默认所有：
- 每日18句
- 自己新增的句子
- DK辅助场景
- 单句“标准音”
- 连续播放
- 默写中的听音

统一使用同一个英文在线发音路径、同一音色。

## 长句
超过约105个字符会按标点/单词自动拆分，
每一段仍使用相同音色连续播放。

## 失败策略
网络失败时：
- 不自动切换机械离线音；
- 直接提示“标准美音加载失败”。
只有用户手工选择“本地离线（仅应急）”时才使用旧离线音。
