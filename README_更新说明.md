# 妈妈英语·180天 V5｜每日自动带句版

- 180天每天第一次打开都会自动生成8句，不需要复制粘贴。
- 主题参考 DK I CAN DO IT 类独立生活技能与《美国家庭亲子英文》类家庭场景；句子为原创自然亲子英语，不逐句复制教材。
- 每句可编辑、删除、朗读、录音；可自己新增到每天最多10句。
- 可点“恢复默认8句”。
- V4已有记录保留，空白日期才自动带句。
