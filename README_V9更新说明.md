# 妈妈英语·180天 V9｜180天扩展 + DK辅助版

## 课程结构
- 180天 = 180个不重复场景主题
- 12大类 × 每类15个场景
- 每天默认18句（目标范围16–20句）
- 同一主题的表达全部集中在同一天
- 可以编辑、删除、自己添加；单日最多20句

## 12大类
晨起与个人卫生、穿衣与整理、吃饭与厨房、家务与独立生活、
玩具与创造力、户外与运动、交通与外出、同伴与社交、
情绪与边界、自然与科学探索、绘本音乐与语言、家庭与睡前。

## DK I Can Do That 辅助模块
新增底部“DK场景”入口。
目前包含61个独立生活技能场景，并提供每个场景的原创亲子英语辅助表达。
其中标有“DK公开示例”的场景来自DK/出版社公开介绍中明确举例的技能。
本APP不复制整本受版权保护的原书文字。

如果后续需要严格按您手头版本做到“原书每一场景逐项对应”，
请上传该书目录或页面，我可以继续补齐。
