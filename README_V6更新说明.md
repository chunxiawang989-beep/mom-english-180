# 妈妈英语·180天 V6｜增强朗读版

## 为什么升级
部分华为/Android浏览器或PWA WebView不提供 Web Speech API 的系统文字朗读。
V6不再把朗读能力绑定在系统TTS上。

## V6朗读架构
1. 自动（推荐）：
   - 优先在线美式发音；
   - 在线失败时，默认课程句自动切换到APP内置离线音频；
   - 再尝试系统语音。
2. 在线美音：
   - 适用于默认句和您自己新增/编辑的句子；
   - 需要联网。
3. 内置离线：
   - 180天课程默认句全部内置，不依赖浏览器系统朗读；
   - 离线也可使用。
4. 系统语音：
   - 仅供支持 SpeechSynthesis 的浏览器使用。

## 建议测试
先把朗读模式切换成“内置离线”，点击任意默认句的“标准音”。
